# Downloadable resources

Drop the free-resource PDFs here. `resource-handler.php` links to them by
exact filename (whitelisted — see the `$RESOURCES` map in that file):

- `va-delegation-checklist.pdf` — The Ultimate VA Delegation Checklist
- `ai-readiness-checklist.pdf`  — AI Readiness Checklist for Small Businesses
- `sop-starter-kit.pdf`         — SOP Starter Kit

Filenames must match exactly. To add a new resource: add a PDF here and a
matching entry in `$RESOURCES` in `resource-handler.php`, plus a card +
button (`data-resource` / `data-title`) in `viava-resources.html`.
